How to fix inaccessible Google Sheets
  1. Open the affected link below using an account with access.
  2. In Google Sheets, click Share → General access → Anyone with the link → Viewer, then click Done (if your organization allows it).
  3. Check that the sheet has a tab named SPES BENEFICIARIES and that the file has not been deleted or moved to trash.
  4. Reload this report to retry. If access must remain restricted, use a properly authorized backend instead of a public browser request.
